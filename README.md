# Smart Agroforestry Morelos - Análisis de Diversificación

Proyecto de Ciencia de Datos para la optimización de la rentabilidad agrícola en Cuautla, Jiutepec y Temixco.

## Stack Tecnológico

- **Lenguaje:** Python 3.10+
- **Análisis de Datos:** Pandas, Numpy, Scipy
- **Base de Datos:** MySQL (SQLAlchemy)
- **Interfaz:** Streamlit
- **Documentación:** LaTeX (APA 7ma)

## Instalación

1. Clonar el repositorio.
2. Configurar el archivo `.env` con las credenciales locales.
3. Ejecutar `pip install -r requirements.txt`.
4. Iniciar el panel con `streamlit run app.py`.
