GUIA DE INSTALACION Y CONFIGURACION (SISTEMA SMART AGROFORESTRY MORELOS)
Proyecto: Smart Agroforestry - Analisis de Diversificacion Agricola
Enfoque: Ciencia de Datos, Inteligencia de Mercado y Streamlit

Esta guia detalla el proceso para preparar el entorno de desarrollo local optimizado para la ejecucion del panel interactivo y el motor de inversion estacional.

1. VISUAL STUDIO CODE (VS Code)
- Paso 1: Descargar desde code.visualstudio.com.
- Paso 2: Instalar marcando la opcion "Agregar al PATH".
- Paso 3: Instalar las extensiones: Python (Microsoft) y MySQL (Weijan Chen).

2. ENTORNO DE DESARROLLO (PYTHON 3.10+)
- Paso 1: Descargar la version mas reciente en python.org.
- Paso 2: CRITICO: Marcar la casilla "Add Python to PATH" durante la instalacion.
- Paso 3: Verificar en terminal con el comando: python --version.

3. BASE DE DATOS (MYSQL)
- Paso 1: Descargar e instalar MySQL Community Server.
- Paso 2: Configurar el usuario root y la contrasenia (asegurate de que coincidan con tu archivo .env).
- Paso 3: Ejecutar el script sistema_agricola_morelos.sql para crear la estructura del Data Warehouse.
- Paso 4: Asegurarse de que el servicio de MySQL este activo antes de ejecutar el dashboard.

4. LIBRERIAS DE CIENCIA DE DATOS Y VISUALIZACION
Abre la terminal de VS Code y ejecuta el siguiente comando para instalar todas las dependencias:

pip install pandas numpy sqlalchemy pymysql streamlit python-dotenv scipy plotly

- pandas/numpy: Procesamiento vectorizado de microdatos del SIAP.
- sqlalchemy/pymysql: Conexion y consultas al catalogo financiero de SQL.
- streamlit: Framework de la interfaz de usuario interactiva.
- plotly: Generacion de graficos de competitividad y tendencia minimalistas.
- python-dotenv: Gestion de credenciales de base de datos.
- scipy: Calculos estadisticos avanzados.

5. ESTRUCTURA DE ARCHIVOS REQUERIDA
Para que las rutas dinamicas funcionen, el directorio debe estar organizado asi:

[CARPETA RAIZ DEL PROYECTO]
|-- app.py                       (Script principal del Dashboard)
|-- 03_modelo_inversion.py       (Motor de estacionalidad y mercado)
|-- database.py                  (Logica de conexion a SQL)
|-- .env                         (Variables de entorno con tus claves)
|-- [Liempeza de Datos]          (Carpeta de datos)
    |-- [Datos Limpios]
        |-- Historico_Morelos_Focalizado.csv

6. CONFIGURACION INICIAL DE GIT (CONTROL DE VERSIONES)
Si es la primera vez que usas Git en el equipo o aparece el error "Author identity unknown", ejecuta los siguientes comandos en la terminal:

git config --global user.email "tu_correo@ejemplo.com"
git config --global user.name "Carlos Emiliano Gonzalez Lopez"

*Nota: Usa el correo asociado a tu cuenta de GitHub/GitLab para mantener la vinculacion de tus contribuciones.*

7. CONFIGURACION DEL ARCHIVO .ENV
Crea un archivo llamado .env en la raiz con el siguiente formato:
DB_HOST=localhost
DB_USER=tu_usuario
DB_PASSWORD=tu_contrasenia
DB_NAME=sistema_agricola_morelos

8. INSTRUCCIONES DE INICIO
- Paso 1: Abre la terminal en la carpeta raiz del proyecto.
- Paso 2: Ejecuta el comando: streamlit run app.py
- Paso 3: El sistema abrira automaticamente el navegador con el dashboard.
