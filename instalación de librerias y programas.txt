GUÍA DE INSTALACIÓN Y CONFIGURACIÓN (STACK MORELOS)
Proyecto: Smart Agroforestry - Análisis de Diversificación Agrícola
Enfoque: Ciencia de Datos, Modelado Financiero y Streamlit

Esta guía detalla el proceso para preparar el entorno de desarrollo local optimizado para el análisis de microdatos del SIAP y la ejecución del panel interactivo.

1. VISUAL STUDIO CODE (VS Code)
Paso 1: Descargar desde code.visualstudio.com.

Paso 2: Instalar marcando la opción "Agregar al PATH".

Paso 3: Instalar las extensiones: Python (Microsoft) y MySQL (Weijan Chen).

2. ENTORNO DE DESARROLLO (PYTHON 3.10+)
Paso 1: Descargar la versión más reciente en python.org.

Paso 2: CRÍTICO: Marcar la casilla "Add Python to PATH" durante la instalación.

Paso 3: Verificar en terminal con: python --version.

3. BASE DE DATOS (MYSQL)
Paso 1: Descargar e instalar MySQL Community Server.

Paso 2: Configurar el usuario root y la contraseña (asegúrate de que coincidan con tu archivo .env).

Paso 3: Ejecutar el script sistema_agricola_morelos.sql para crear la estructura del Data Warehouse.

4. LIBRERÍAS DE CIENCIA DE DATOS Y STREAMLIT
Abre la terminal de VS Code y ejecuta el siguiente comando para instalar todas las dependencias necesarias:

pip install pandas numpy sqlalchemy pymysql streamlit python-dotenv scipy
pandas/numpy: Procesamiento de los archivos CSV del SIAP.

sqlalchemy/pymysql: Conexión robusta con la base de datos MySQL.

streamlit: Generación del panel web interactivo.

python-dotenv: Gestión segura de credenciales de base de datos.

scipy: Ejecución de cálculos para integrales y modelos probabilísticos.

INSTRUCCIONES DE INICIO RÁPIDO
Configuración: Asegúrate de tener el archivo .env en la raíz con tus credenciales de MySQL.

Datos: El archivo Historico_Morelos_Focalizado.csv debe estar en la misma carpeta que los scripts.

Ejecución: Para iniciar el panel de control, usa el comando:

streamlit run app.py

En caso de que no funcione el comando anterior, puedes intentar con:

python -m streamlit run app.py
