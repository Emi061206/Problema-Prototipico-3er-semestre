GUIA DE INSTALACION Y CONFIGURACION (SISTEMA SMART AGROFORESTRY MORELOS)
Proyecto: Smart Agroforestry - Analisis de Diversificacion Agricola
Enfoque: Ciencia de Datos, Inteligencia de Mercado y Analisis Contable

Esta guia detalla el proceso para preparar el entorno de desarrollo local optimizado para la ejecucion del panel interactivo, el motor de inversion y la generacion de reportes ejecutivos.

1. VISUAL STUDIO CODE (VS Code)
* Descargar desde code.visualstudio.com.
* Instalar marcando la opcion "Agregar al PATH".
* Instalar extensiones: Python (Microsoft) y MySQL (Weijan Chen).

### 2. Guía de Instalación (Actualizada)

```text
GUIA DE INSTALACION Y CONFIGURACION (SISTEMA SMART AGROFORESTRY MORELOS)
Proyecto: Smart Agroforestry - Analisis de Diversificacion Agricola (Version Dash)

1. ENTORNO DE DESARROLLO (PYTHON 3.10+)
- Descargar la version mas reciente en python.org.
- CRITICO: Marcar la casilla "Add Python to PATH" durante la instalacion.

2. BASE DE DATOS (MYSQL)
- Cargar el archivo "sistema_agricola_morelos.sql".
- Asegurar que la tabla "catalogo_cultivos" refleje la inversion inicial de $147,000.00.

3. INSTALACION DE LIBRERIAS
Ejecutar el siguiente comando en la terminal para instalar el motor grafico y financiero:

pip install dash dash-bootstrap-components pandas numpy plotly reportlab scipy python-dotenv mysql-connector-python

4. CONFIGURACION DEL ARCHIVO .ENV
Crear un archivo .env en la raiz con el siguiente formato:
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=tu_contrasenia
DB_NAME=sistema_agricola_morelos
DB_PORT=3306

5. ESTRUCTURA DEL REPOSITORIO
- app.py: Aplicacion principal (Dash) y Callbacks reactivos.
- motor_financiero.py: Logica de punto de equilibrio y generador PDF.
- Historico_Morelos_Focalizado.csv: Microdatos agricolas 2018-2024.
